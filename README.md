# 🍔 Hamburgueria

Um projeto de uma **hamburgueria online**, desenvolvido para apresentar um cardápio de lanches de forma moderna, simples e interativa.

## 🚀 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

## 🍟 Sobre o projeto

O projeto **Hamburgueria** foi desenvolvido como uma aplicação web para simular uma página de pedidos de uma hamburgueria.

A interface apresenta diferentes opções de lanches e permite que o usuário interaja com os produtos, proporcionando uma experiência simples e intuitiva para visualizar o cardápio e realizar pedidos.

## ✨ Funcionalidades

* 🍔 Exibição dos lanches disponíveis
* 🛒 Interação com os produtos
* 💰 Exibição dos preços
* 📋 Visualização do cardápio
* ⚡ Interface dinâmica e interativa
* 📱 Layout adaptado para diferentes dispositivos

## 🧠 Conceitos praticados

Durante o desenvolvimento do projeto, foram aplicados conceitos como:

* Estruturação de páginas com HTML5
* Estilização e responsividade com CSS3
* Manipulação do DOM com JavaScript
* Eventos e interações com o usuário
* Funções JavaScript
* Manipulação de elementos HTML
* Organização e apresentação de produtos
* Lógica de programação
